mic-bridge 旧平板麦克风桥 v0.6.0
================================

作用：把一台旧 Android 平板变成 Windows 能用的麦克风。

  平板采麦 → USB(adb reverse) 或 WiFi → 本机接收端 → VB-Cable 虚拟声卡
  → Windows 多出录音设备 "CABLE Output"，任何程序都能选它当麦克风

一、前置条件
------------
1. VB-Cable 虚拟声卡（必需）
   授权不允许随本安装包分发，需要单独安装：
   下载 https://vb-audio.com/Cable/  →  VBCABLE_Driver_Pack45.zip
   解压后以管理员身份运行 VBCABLE_Setup_x64.exe

2. 平板：设置 → 开发者选项 → USB 调试（打开）
   没有"开发者选项"：设置 → 关于平板 → 连点"版本号" 7 次

3. 数据线必须能传数据，纯充电线不行

二、启动与托盘
--------------
装完后从开始菜单或桌面点「mic-bridge 麦克风」启动。
程序没有窗口，常驻在屏幕右下角托盘（Win11 默认收在 ^ 隐藏图标里，
可把它拖到任务栏常显）。

托盘图标颜色就是状态：
    绿色 = 推流中（平板正在送话）
    灰色 = 等待平板连接
    红色 = 出故障（鼠标悬停看原因）

鼠标悬停图标可看一句话详情（链路 / 模式 / 速率）。

右键菜单：
    状态行            当前状态一览
    切换 USB ⇄ WiFi   重启接收端换链路（USB 约百毫秒延迟，WiFi 约 300ms）
    显示诊断日志       弹出实时滚动日志窗口，排查问题用
    退出              完全退出

三、设置默认麦克风
------------------
设置 → 系统 → 声音 → 输入 → 选择
    CABLE Output (VB-Audio Virtual Cable)

设成默认后，微信/QQ 语音、Win+H 听写、CapsWriter 等无需改配置。

四、常见问题
------------
- 右下角没有图标 / 双击没反应
    可能已经有一个实例在运行（重复启动会弹提示）。先在托盘找绿点。

- 找不到平板
    换一根能传数据的线、换 USB 口；确认平板上已点"允许 USB 调试"

- 平板在放音但电脑没反应，图标却是绿色
    极少数情况下隧道会"假活"。托盘右键 → 切换 WiFi 再切回 USB，
    相当于重置链路；或退出后重新启动。

- 诊断日志在哪
    %LOCALAPPDATA%\mic-bridge\receiver.log（超 1MB 自动换 .old）
    托盘右键 → 显示诊断日志 可实时看

- 平板熄屏后被杀
    App 自带 wakelock，但 MTK 老机型仍可能清理后台；长期使用建议插线供电

五、文件说明
------------
mic-bridge-receiver.exe   接收端（内置 adb 与平板 APK，托盘常驻无窗口）
mic-bridge-0.5.0.apk      平板端 App（接收端会自动装/升级，也可手动 adb install -r）
启动USB接收端.bat          诊断用：USB 模式起一个实例
启动WiFi接收端.bat         诊断用：WiFi 模式起一个实例

版本：接收端 0.6.0 / 平板端 0.5.0
